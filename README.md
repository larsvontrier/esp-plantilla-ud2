# UD2. Práctica: estructura y depuración de un script

Módulo 5098. Entornos y sintaxis en Python.

Esta plantilla sirve para practicar la estructura de un script, la lectura de mensajes de error, la depuración y el análisis del código antes y después de corregirlo. El trabajo se entrega en `ANALISIS.md` y en `src/principal.py`.

## Antes de empezar

1. Comprueba que el repositorio es **privado**, está en tu cuenta personal y tiene el nombre `5098-ud2-<usuario>` (donde `usuario` es tu nombre de GitHub).
2. Invita como colaboradora a la cuenta del profesorado indicada en el aula virtual: **Settings**, **Collaborators**, **Add people**.
3. Clona el repositorio y trabaja siempre dentro de la carpeta clonada.

## Enunciado

Lee [`ENUNCIADO.md`](ENUNCIADO.md) antes de empezar. Analiza el script inicial, ejecútalo, utiliza los mensajes que aparezcan para depurarlo y completa el análisis antes y después de la corrección. La solución utiliza únicamente asignaciones, expresiones y `print()`; no se deben añadir estructuras de control.

## Historial

Realiza al menos **cuatro commits propios**, repartidos a lo largo del trabajo y con mensajes descriptivos. Un único commit final no se considera válido.

## Entrega

1. Envía todo el trabajo con `git push` y comprueba con `git status` que la rama está al día con `origin/main`.
2. Abre la página del repositorio en GitHub y copia el hash abreviado del último commit (siete caracteres).
3. Entrega en la tarea del aula virtual, antes de la fecha de cierre, un texto con estas dos líneas:

```text
Repositorio: https://github.com/usuario/5098-ud2-usuario
Commit: a1b2c3d
```

La versión corregida es la del commit indicado. Si el plazo sigue abierto, puedes actualizar la entrega con un hash nuevo.
